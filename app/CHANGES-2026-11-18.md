# Unguided — change notes, 18 Nov 2026

Built from `unguided-app-for-james-20261118.zip`.
This zip is that project plus the changes below. Unzip it over your copy; there are no new dependencies.

## Why

On an iPhone 15 Pro Max with a larger **Text Size** (Settings › Display & Brightness › Text Size), the sign-in title wrapped to "Unguide / d".
React Native scales every `<Text>` by that setting. Most display text in the app was sized for the default with no room to grow.
Separately, the Timer's LED clock is 374pt wide at its fixed size. That is wider than the content area of a standard (non-Max) iPhone, so it overflowed even at default text size.

## What changed

### New file: `src/textFit.ts`

Shared presets so the rule is decided in one place:

| Export | Effect | Use for |
|---|---|---|
| `oneLine` | `numberOfLines={1}` + shrink-to-fit (down to 40%) | Headings that must stay on one line |
| `twoLines` | Up to 2 lines, shrinking only if still too big | Card titles |
| `CHROME_MAX_SCALE` (1.3) | Caps how far text grows with the phone's setting | Header, footer, game HUDs and overlays |

Text inside a fixed-size box uses `allowFontScaling={false}` directly.

### Behaviour by kind of text

| Kind of text | Behaviour now | Where |
|---|---|---|
| Body text, buttons, forms | **Unchanged** — still follows the phone's text size | Everywhere |
| One-line headings | Shrink to fit instead of wrapping | Sign-in title, Profile name, Chamber lobby title and persona names, Chamber chat header, Timer state title ("UP 20:00"), leaderboard title and rank |
| App chrome and game UI | Grow with the setting, capped at 1.3× | AppHeader, TimerFooter, Pac-Man and Snake score rows, overlays, buttons, leaderboard chip, dial labels |
| Fixed-size boxes | Ignore the text-size setting | Timer LED digits, dial digits, header back chevron, chat back arrow, Pac-Man D-pad arrows, Snake ‹ › glyphs, footer ✕ |
| Home feature card titles | Up to 2 lines, then shrink | "Percentage Calculator" etc. |
| Single-line truncation | `numberOfLines={1}` | Leaderboard player names, chat presence line, footer labels, Snake RX/Scaled pills, header 🚀 Chamber button |

### Layout changes

- **Timer clock (`screens/TimerScreen.tsx`)** scales to the screen width with `useWindowDimensions`. Wells, colon, padding and digit size all scale by the same factor. It is full size on phones wide enough (e.g. Pro Max) and scales down on narrower ones. The constants are documented next to `CLOCK_NATURAL_W`.
- **AppHeader (`components/AppHeader.tsx`)** — the wordmark, byline and name can now shrink (`flexShrink: 1`). The name area is capped at 38% of the row, so a long display name can't push out the page title.
- **Sign-in title** — removed a duplicate inline `letterSpacing: 3` (it was already in the style).

### Files touched

`src/textFit.ts` (new), `screens/`: SignInScreen, TimerScreen, OpenGymLanding, ProfileScreen, PacManScreen, SnakeScreen, ChamberLanding, ChamberChat; `components/`: AppHeader, TimerFooter, DialValue, WWT10Overlay.

Not touched: `PacManStub.tsx` and `ChamberStubScreen.tsx`, because `App.tsx` no longer uses them.

## iOS project (first `pod install`)

The previous zip's Xcode project had never had `pod install` run against it. This one has, so it builds as-is after installing pods:

- `ios/Unguided.xcodeproj/project.pbxproj` now includes the CocoaPods/Expo integration (Pods xcconfigs, `[Expo] Configure project`, `[CP] Embed Pods Frameworks`, `ExpoModulesProvider.swift`).
  The bundle ID is still `com.aldubai.opengym` and no signing team is set; pick yours in Xcode.
- New: `ios/Podfile.lock`, `ios/Unguided/PrivacyInfo.xcprivacy`.
- New: `Gemfile`, `Gemfile.lock`, `.bundle/config`. These pin CocoaPods so it installs on macOS's built-in Ruby 2.6 with no Homebrew needed (`ffi < 1.17` is the key pin):

```bash
bundle install                          # once, installs into vendor/bundle
cd ios && bundle exec pod install && cd ..
open ios/Unguided.xcworkspace
```

Left out of the zip: `node_modules`, `ios/Pods`, `ios/build`, `ios/Unguided.xcworkspace` (recreated by `pod install`), `vendor/`, `ios/.xcode.env.local` (machine-specific), Android `.cxx`/`.kotlin` build output.

## Verified

- `npx tsc --noEmit`: no new errors. There is one existing error, not from these changes: `components/pickCsvFile.ts(107,61)`, `.message` on `{}`.
- Release build for a device succeeded (Xcode 26.5, Intel Mac). Installed and launched on an iPhone 15 Pro Max running iOS 26.6.2 with a larger text size.

## Not verified

- How each screen looks at every text size (the sign-in fix was the one reported).
- Smaller iPhones and iPad. The timer scaling is computed, not checked visually.
- Android and web. The props used are standard React Native, and `allowFontScaling`/`maxFontSizeMultiplier` apply on Android too.
- No lint run (ESLint isn't installed in the project).

## Worth knowing (unchanged, flagged while building)

- `config/app-config.ts` contains the Storm passphrase in plain text. Its own comment says to set it to `null` for anything beyond local dev.
- `README-IOS-BUILD.md` says `cd app`, but the zip has `package.json` and `ios/` at the top level.
- React Native 0.88 asks for Node 22, 24 or 26+. Node 25 installs with warnings and builds fine.
